# Internationalisation

### REQ-LANG-001: German, English, Polish and Russian

- **Priority:** must | **Phase:** 1 | **Status:** implemented | **Verify:** test | **Source:** user (2026-11-04, Russian added 2026-11-10)

All UI text must be available in German, English, Polish and Russian. The initial language follows the browser
(fallback English); the user can switch it with a language selector, and the choice is remembered. The app name is not translated.

### REQ-LANG-002: Correct plurals

- **Priority:** must | **Phase:** 1 | **Status:** implemented | **Verify:** test | **Source:** user (2026-11-04)

Messages with a count must use the plural rules of the language (e.g. Polish and Russian have one, few and many forms).
